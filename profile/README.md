## How our labs work

- Every course is labs first: short talks, hands on keyboards fast.
- Each lab repo has a checkpoint per module: tags `mNN-start` and `mNN-done`. Fall behind? Check out the last `-done` tag and carry on.
- Labs use synthetic data only. Never bring production credentials or customer data into a class.

Most lab repos are private and are handed to enrolled participants as part of their class pack.
